L1 Informatique

Histoire

La Création (1994 - 1996)

Au début des années 90, le HTML servait uniquement à structurer du texte (titres, paragraphes). Pour changer une couleur ou une police, les développeurs utilisaient des balises comme <font>, ce qui rendait le code illisible et difficile à maintenir.

C'est Håkon Wium Lie, travaillant au CERN aux côtés de Tim Berners-Lee, qui publie la première proposition de Cascading HTML Style Sheets en octobre 1994. Son idée de génie ? Le concept de "Cascade", permettant à plusieurs feuilles de style de s'empiler et de définir des priorités.

Le premier standard (1996)

Le W3C (World Wide Web Consortium) approuve la recommandation CSS 1 en décembre 1996.

  • Capacités :

    Polices, couleurs de texte, alignement et marges de base.

  • Le problème : Les navigateurs de l'époque (Internet Explorer 3 et Netscape Navigator 4) interprétaient les règles de manière très aléatoire, créant des cauchemars pour les développeurs.

Le positionnement et l'ambition (1998)

Arrivé très vite en 1998, le CSS 2 apporte des concepts fondamentaux encore utilisés aujourd'hui :

  • Le positionnement (absolute, relative).
  • Les types de médias (pour l'impression).
  • Les sélecteurs plus complexes.

C'est à cette époque que le Modèle de Boîte (Box Model) devient central, définissant comment le contenu, le rembourrage (padding), la bordure et la marge interagissent.

La modularisation (Depuis 1999)

Contrairement aux versions précédentes, le CSS 3 n'est pas un bloc monolithique. Le W3C a décidé de le diviser en modules indépendants (Couleurs, Flexbox, Animations, etc.) pour permettre des mises à jour plus rapides sans attendre que tout le langage évolue.

2000 - 2010 : Une période de transition lente, marquée par la domination d'Internet Explorer 6 qui freinait l'adoption des nouveautés.

Introduction au CSS

Cascading Style Sheets ou CSS, est un langage principalement utilisé pour la stylisation de pages web. Il s’utilise surtout avec un autre langage nommé HTML afin d’améliorer la qualité esthétique d’un site, afin qu’il soit plus moderne et plus maniable dans son utilisation.

Sans lui, la page HTML serait simplement du texte brut avec très peu de mise en forme.

Grâce au CSS, il est possible de modifier : les couleurs, les polices, les tailles, les espacements, les animations et la disposition des éléments.

Exemple pratique :

HTML :

<p>Hello World</p>

CSS :

Hello World

p {
  color: red;
  font-size: 30px;
}

Dans cet exemple, le texte devient rouge et sa taille passe à 30 pixels. Le CSS est aujourd’hui indispensable dans le développement web moderne.

Les bases de la syntaxe en CSS

Une règle CSS est composée de trois parties : Le sélecteur, La propriété, et La valeur.

  • Le sélecteur : sert à choisir les éléments HTML qui vont être stylisés. Il en existe plusieurs ayant chacun des attributs bien déterminés (balise, classe, identifiant, universel, descendant).
  • La propriété : sert à définir ce qu’on veut modifier sur un élément. Le sélecteur choisit qui sera modifié, la propriété choisit quoi modifier.
  • La valeur : correspond à ce qu’on donne à une propriété (ex: une couleur spécifique ou une taille).
/* Structure de base */
sélecteur {
  propriété: valeur;
}

Les couleurs et les textes

Le CSS permet de personnaliser entièrement l’apparence du texte et des couleurs d’un site web. Grâce à ce dernier, on peut changer la couleur du texte, la couleur de fond, la taille des lettres, la police d’écriture, l’alignement ou encore ajouter des effets.

Exemples d'utilisation :

Changer la couleur du texte :

p { color: blue; }

Appliquer une police d'écriture :

p { font-family: Arial; }

Aligner un titre au centre :

h1 { text-align: center; }

En combinant ces propriétés, on peut créer des interfaces modernes et agréables à regarder. Le design typographique est essentiel pour améliorer la lecture d’un site web.

Les marges et espacements

En CSS, les marges et les espacements permettent d’organiser les éléments d’une page web afin d’améliorer la lisibilité, l’esthétique et l’expérience utilisateur. Une bonne gestion des espaces rend une interface plus claire, plus moderne et plus professionnelle.

Différence entre margin et padding :

Propriété Rôle
Margin Espace extérieur (autour de la bordure)
Padding Espace intérieur (entre le contenu et la bordure)

Illustration du Modèle de Boîte (Box Model) :

MARGIN (Extérieur)
PADDING (Intérieur)
CONTENU

Importance des espacements :

Une bonne utilisation des marges et du padding permet d'aérer la page, d'améliorer la lecture, de mieux séparer les sections, de rendre le design moderne et d'éviter une interface surchargée.

NB : Une bonne gestion du margin et du padding permet de créer des interfaces élégantes, modernes et agréables à utiliser.

Les sélecteurs CSS

Les sélecteurs CSS permettent de cibler les éléments HTML afin d’appliquer des styles. Ils sont essentiels pour personnaliser l’apparence d’une page web et organiser efficacement le design.

p {
  color: blue;
}

Dans l'exemple ci-dessus, tous les paragraphes du document cible (balises <p>) deviennent bleus.

Responsive Design et les Media Queries

Le Responsive Design (ou design adaptatif) est l'art de créer des sites web qui s'ajustent automatiquement à la taille de l'écran de l'utilisateur, qu'il soit sur un smartphone, une tablette ou un ordinateur de bureau.

1. La balise Meta Viewport

Avant d'écrire du CSS, il faut indiquer au navigateur comment gérer l'affichage sur mobile dans le fichier HTML (entre les balises <head>) :

<meta name="viewport" content="width=device-width, initial-scale=1.0">

2. Les Media Queries

Une Media Query est une règle qui permet d'appliquer du CSS seulement si certaines conditions sont remplies (généralement la largeur de l'écran).

/* Style par défaut (Mobile First) */
p { font-size: 14px; }

/* Style pour les écrans de plus de 768px (Tablettes/PC) */
@media (min-width: 768px) {
  p {
    font-size: 18px;
    color: darkblue;
  }
}

3. Les points de rupture (Breakpoints) courants :

  • Mobile : Jusqu'à 480px.
  • Tablette : De 481px à 768px.
  • Ordinateur : Au-delà de 769px.

Flexbox et Grid (Mise en page moderne)

Grâce au CSS, il est possible de modifier la disposition des éléments de manière très précise. Flexbox et Grid sont les deux systèmes indispensables pour organiser vos blocs.

1. Flexbox : L'alignement flexible

Idéal pour aligner des éléments sur une seule dimension (soit en ligne, soit en colonne). Utilisé pour les barres de navigation, aligner des icônes ou centrer un élément.

  • Activé sur le parent avec : display: flex;
  • justify-content gère l'alignement horizontal.
  • align-items gère l'alignement vertical.

2. CSS Grid : La structure en grille

Contrairement à Flexbox, CSS Grid travaille sur deux dimensions à la fois (les lignes ET les colonnes). C'est l'outil parfait pour créer la structure globale d'une page (header, barre latérale, zone de contenu, footer).

  • Activé sur le parent avec : display: grid;
  • Définition des colonnes : grid-template-columns: 1fr 2fr; (crée une petite colonne et une grande).

Conclusion

Comme nous l'avons vu tout au long de ce guide, le CSS est le moteur esthétique du web. Depuis sa création par Håkon Wium Lie en 1994, il n'a cessé d'évoluer pour offrir aux développeurs des outils de plus en plus puissants et précis.

Ce qu'il faut retenir :

  • La séparation des rôles : Le HTML structure le contenu brut tandis que le CSS gère toute l'apparence.
  • La précision : Grâce aux sélecteurs, aux propriétés et aux valeurs, vous avez un contrôle total sur chaque pixel de votre site.
  • L'organisation : Une bonne gestion du "Modèle de Boîte" (marges et espacements) est le secret d'une interface moderne et lisible.
